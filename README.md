# 团结餐桌 · Unity Feast

![v1.2.0](https://img.shields.io/badge/version-v1.2.0-blue)

为 Minecraft 加入东百和老广的虐恋。

## 玩法

1. 木头制作桌子，小麦与生猪肉制作饺子。
2. 主手拿普通饺子或生鱼右键桌子放置，四个桌角可混放，总共最多四份。
3. 主手空手右键取出一个实际掉落物：饺子变桌饺，生鱼变臭鱼，放入后即可取出。
4. 正常成功钓鱼时独立判定 50%，命中则把本次钓获替换为一个水蟑螂。
5. 水蟑螂和小麦合成清水龙虱打边炉。
6. 清水龙虱打边炉与桌饺合成团结之心。
7. 食用团结之心后增加 2 点生命上限，恢复全部生命、饥饿值与饱和度。
8. 在猪等普通动物出没的群系遇到中立的老鼠，击杀后获得三吱，也可以用小麦喂食繁殖。
9. 用清水龙虱打边炉、臭鱼、三吱和两个桌饺制作味极鲜；食用一次增加 20 点生命上限。
10. 用八个团结之心围住味极鲜合成机长，放在副手后双击跳跃即可飞行。
11. 在新区域采收绿化带，留下叶片种植；三个可可豆装满酱缸，用碗取出大酱，再制作蘸酱菜。
12. 将生猪排、生鲑鱼或生鸡肉放在菜板上，用菜刀切割即可得到猪肉生、生鱼片或白切鸡。

## 桌子与生鱼

生鳕鱼、生鲑鱼、热带鱼、河豚都能放上桌，其他模组的生鱼可通过 `unity_feast:raw_fish` 材料标签兼容。熟鱼和鱼桶不能放入，桌饺和臭鱼不能再次加工。

## 老鼠

老鼠是棕色的小型中立动物，有四条腿和长尾巴，会像猪、牛、羊一样自行游走，也能小跑和跳过一格障碍。生命值为 10，普通近战基础伤害为 1；只有受到生物攻击才会报复实际攻击者，不会召集其他老鼠。双方碰撞箱接触且无遮挡时才能命中，攻击间隔至少一秒。

老鼠采用与猪相同的生成群系、地面和光照要求，原版默认生成权重为 10，每群尝试生成 4 只。它会参与新区块的初始生成，已有区块不会重新初始化；后续自然刷新共享原版动物数量上限。

老鼠会寻找周围 15 格内种在耕地上的小麦，不论麦苗处于哪个生长阶段，都会尝试走过去啃食。吃掉后麦苗直接消失、不掉落小麦或种子，脚下的耕地变回泥土。障碍会影响它的接近；关闭“生物破坏”规则时不会毁坏农田。自行啃食麦苗不会触发繁殖。

手持小麦可以吸引老鼠。分别给两只老鼠喂食小麦，它们会像普通动物一样进入爱心状态、靠近并繁殖；生存模式下每只消耗一个小麦，小麦种子不能代替。每次生出一只普通体型的老鼠，没有幼鼠或幼年成长期；双亲保留原版五分钟的繁殖冷却。

亮度低于 7，或正在报复时，眼睛会变红并在黑暗中发光。仅因黑暗变红眼不会主动攻击。正常死亡固定掉落一个三吱，抢夺不增加数量，并遵守生物掉落规则。

## 机长

中国人能飞。

仅在副手持有时允许创造模式式飞行：双击跳跃起飞／退出，使用原版上升、下降和移动操作，可以悬停。

取下后，若没有创造／旁观模式或其他飞行来源，就会退出飞行并正常下落。

## 绿化带

绿化带是一株生菜。在地形原本出现短草的位置，约 20% 会改为成熟绿化带，其余仍是短草。

采收得到的生菜叶既能吃，也能直接种。

## 酱缸与蘸酱菜

酱缸用七个红砖合成。拿可可豆右键，每个必定增加一节，三个恰好装满。空碗右键满缸，一次取得一份大酱，并将整缸清空。

大酱吃完返还一个空碗；用大酱合成蘸酱菜同样返还一个空碗。吃蘸酱菜不再返碗。破坏酱缸只掉落空缸，尚未取出的酱会丢失，精准采集也不保留酱量。

```text
酱缸 ×1                 蘸酱菜 ×3
红砖  空  红砖           绿化带  绿化带  绿化带
红砖  空  红砖             空     大酱     空
红砖 红砖 红砖

菜刀 ×1                 菜板 ×1
铁锭                    木板  木板  木棍
木棍
```

菜刀的铁锭与木棍必须上下相邻，可在随身或工作台任意合法位置合成。菜板的两个木板必须是同一种木板。

## 菜刀与菜板

菜板放在有完整顶面支撑的方块上，可以调整水平朝向。手持原料右键放入一份，空手右键取回未加工原料；已有原料时不能再放入。主手拿菜刀右键，一次完成加工并掉出成品。

| 放入原料   | 一次加工产出 |
| ---------- | ------------ |
| 生猪排 ×1 | 猪肉生 ×1   |
| 生鲑鱼 ×1 | 生鱼片 ×2   |
| 生鸡肉 ×1 | 白切鸡 ×1   |

只接受三种生食材，熟肉、生鳕鱼和成品都不能放入。

菜刀主手基础攻击力为 4、攻击速度为 1，耐久为 251。
