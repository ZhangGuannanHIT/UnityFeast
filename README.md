# 团结餐桌 · Unity Feast

为 Minecraft 加入东百和老广的虐恋。
制作饺子、摆上餐桌，钓鱼获得的水蟑螂、制作清水打边炉，组合成能够生死人肉白骨的团结之心。

## 玩法

1. 木头制作桌子，小麦与生猪肉制作饺子。
2. 主手拿普通饺子右键桌子放置，最多放四个。
3. 主手空手右键取出一个掉落的桌饺。
4. 正常成功钓鱼时独立判定 50%，命中则把本次钓获替换为一个水蟑螂。
5. 水蟑螂和小麦合成清水龙虱打边炉。
6. 清水龙虱打边炉与桌饺合成团结之心。
7. 完整食用团结之心后增加 2 点生命上限，恢复全部生命、饥饿值与饱和度。

| 食物           | 恢复饥饿值 | 效果                                              |
| -------------- | ---------: | ------------------------------------------------- |
| 饺子           |          4 | 无                                                |
| 桌饺           |          4 | 清除负面状态效果；伤害吸收 I、生命恢复 I 各 15 秒 |
| 水蟑螂         |          1 | 反胃（眩晕）5 秒                                  |
| 清水龙虱打边炉 |          8 | 防火 I、缓降 I 各 15 秒                           |
| 团结之心       |  补满至 20 | 生命上限 +2，生命补至新上限，饱和度 20            |

实际死亡时，开启“死亡不掉落”则保留奖励，关闭则清除；采用死亡瞬间的规则，复活前改规则不追溯。
不死图腾阻止死亡不会清除奖励。

## 配方

```text
桌子 ×1                 饺子 ×3
木板  木板  木板          空    空    空
木棍   空   木棍          空   生猪肉  空
木棍   空   木棍         小麦  小麦  小麦

清水龙虱打边炉 ×1
  空      空      空
水蟑螂  水蟑螂  水蟑螂
 小麦    小麦    小麦

团结之心 ×1（无序）
桌饺 ×1 + 清水龙虱打边炉 ×1
```

桌子的三个木板须为同一种木板，混合木板无效。
